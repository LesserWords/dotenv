# Terpsikhore Theme

Warm Solarized spinoff for Visual Studio Code — **Terpsikhore Light** (beige / vanilla) and **Terpsikhore Dark** (espresso with light brown accents).

Parent folder overview: [../README.md](../README.md) · Repo root: [../../README.md](../../README.md)

## Install

Search `Terpsikhore Theme` in the Extensions panel, or:

```sh
ext install Terpsikhore.terpsikhore-theme
```

## Customize

Override any token in your `settings.json`:

```json
"editor.tokenColorCustomizations": {
  "[Terpsikhore Dark]": {
    "comments": "#8A7B62"
  }
}
```
